Mathematics · Friday mix: the ambiguous case, no, one, or two triangles

40 min · Friday mix · invented SSA cases, acute and obtuse; exact values; no official measurements

Learn

Key terms (from earlier lessons)

  • the ambiguous case (SSA) — Day 146

Open a card if you need a reminder; then close it and use the term in your own words.

Friday mixes this week’s ambiguous case. For acute A, compare a with h = b sin A: no triangle if a < h; one right triangle if a = h; two triangles if h < a < b; one triangle if a ≥ b. For obtuse A, no triangle if a ≤ b, and one triangle if a > b. The set invented figures remain A = 30°, b = 2, with h = 1, and the obtuse invented figures A = 120°, b = 2. Exact work keeps sin 30° = 1/2, sin 120° = √3/2, and, in the two-triangle case, sin B = 1/√2. Official measured sides are not invented.

Remember

SSA does not always determine one triangle. On the invented acute figures, a = 1/2, 1, √2, and 2 give none, one right, two, and one isosceles triangle. On the invented obtuse figures, a must be greater than b for a triangle to occur.

Watch me

On invented figures with A = 30° and b = 2, state how many triangles if a = 1/2, a = 1, a = √2, and a = 2, and name the triangles that occur.

  1. a = 1/2: none. a = 1: one right triangle. a = √2: two triangles, 30°-45°-105° and 30°-135°-15°. a = 2: one isosceles triangle, 30°-30°-120°.
  2. h = 1 throughout these four.
  3. The figures are invented.

Together

On invented figures with A = 120° and b = 2, what happens if a = 2, and what triangle appears if a = 2√3?

Hint 1: Obtuse A

If a ≤ b, there is no triangle.

Hint 2: The longer opposite side

If a = 2√3, the triangle is 120°-30°-30°.

Check

  1. State the acute SSA rule, including h = b sin A, and the obtuse SSA rule.
  2. On invented figures with A = 30° and b = 2, give the four results for a = 1/2, a = 1, a = √2, and a = 2.
  3. On invented figures with A = 120° and b = 2, what happens if a = 2, and what triangle appears if a = 2√3?

Exercises

  3. What official figure must you not invent?

A refutation shows why a claim does not hold. The set invented claim, “If two sides of a triangle are equal, the angles opposite those sides are equal.” holds, from already-taught isosceles geometry. Physics · Friday mix: closed and open air columns, and official Example 17.5

40 min · Friday mix · OpenStax 17.5; open-tube formula f_n = n v_w / (2L), n = 1, 2, 3, …; official lengths not invented

Learn

Key terms

resonance in an open air column
Definition
In OpenStax 17.5, a tube open at both ends has antinodes of air displacement at both ends. The resonant frequencies are f_n = n v_w / (2L), with n = 1, 2, 3, …. The fundamental is twice the fundamental of a closed tube of the same length. Official instrument lengths are not invented.
Example
The book notes that a tube open at both ends has a fundamental frequency twice what it would have if closed at one end, and a different spectrum of overtones. An invented check, labeled invented, may use this week’s official Example 17.5 speed 344 m/s with an invented length, but must not treat that length as official.
Not this
Not a closed tube, whose odd-n series was already taught. Not official Example 17.5 reused as if it were an open tube. Not an official length of a flute or organ pipe. Not a copyrighted score or an official concert pitch.
Connects to
This week’s closed-tube resonances and official Example 17.5. Later optics remain reserved.

Friday first adds the tube open at both ends, still from OpenStax 17.5, and then mixes it with this week’s closed tube and official Example 17.5. A tube open at both ends has antinodes of air displacement at both ends. The book’s resonant frequencies are f_n = n v_w / (2L), with n = 1, 2, 3, …. The fundamental is f_1 = v_w / (2L), twice the fundamental of a closed tube of the same length, and the overtones include every integer n, not only the odd values. The book notes that two tubes with the same fundamental, one open and one closed, would sound different because they have different overtones. Official instrument lengths are not invented.

Official Example 17.5 remains a closed tube: 22.0°C, v_w = 344 m/s, 128 Hz, L = 0.672 m, fourth overtone 1.15 kHz. An invented check, labeled invented, may use that official speed with an invented length: if L = 1.00 m, not official, a closed fundamental would be 344 / 4 = 86.0 Hz, and an open fundamental 344 / 2 = 172 Hz. Do not treat 1.00 m, 86.0 Hz, or 172 Hz as official textbook example values.

Remember

An open tube has antinodes at both ends, and f_n = n v_w / (2L), with n = 1, 2, 3, …. Its fundamental is twice that of a closed tube of the same length. Official Example 17.5 remains the closed 0.672 m tube at 344 m/s.
