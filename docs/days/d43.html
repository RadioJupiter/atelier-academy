Latin · Review of Capitula I–X: the present, and the active infinitive

40 min · Method: picture-based Latin; original sentences. Instruction in English. A review, not a new chapter.

Learn

Key terms

present infinitive, active
Definition
The ‘to …’ form of a verb, in the present, active: vidēre, ‘to see.’ It can sit with a verb such as potest (‘is able’).
Example
Puella vidēre potest. Puer puellam videt is a finite present, not an infinitive.
Not this
The infinitive is not a past tense, and it is not the passive infinitive reviewed in Capitulum X (that was a different ending, already taught, not re-opened as a new chapter today).
Connects to
Yesterday’s nouns still supply the subjects and objects (puellam is the object form you already have).
Word How to say it Meaning
videt WEE-det he/she/it sees (present)
vidēre wi-DAY-reh to see (present infinitive, active)
Puer puellam videt POO-ehr poo-ELL-ahm WEE-det The boy sees the girl
Puella vidēre potest poo-ELL-ah wi-DAY-reh POS-test The girl is able to see

Original sentences: Puer puellam videt. Puella puerum videt. Puella vidēre potest. Puer nōn videt.

Mathematics · Algebra XIV: composition and the inverse

60 min · Method: the inverse already taught, then composition both ways, then the identity

Learn

Key terms

identity function
Definition
The function that sends every allowed x to x itself, often written id(x) = x. It is the result of composing a function with its inverse, when that inverse exists.
Example
If f(x) = 2x + 1, then f⁻¹(x) = (x − 1)/2, and (f ∘ f⁻¹)(x) = 2((x − 1)/2) + 1 = x. Likewise (f⁻¹ ∘ f)(x) = x.
Not this
Not the logic inverse of a statement (Day 21 / Day 39). And not “multiply by 1” as a claim about a different function f; the identity is its own function, id(x) = x.
Connects to
The inverse of a linear function (Algebra XII) and yesterday’s composition. f and f⁻¹ undo each other because their composition is the identity.

Day 39 taught the inverse of a linear function: if f(x) = mx + b with m ≠ 0, then f⁻¹(x) = (x − b)/m. Day 41 taught composition. Today those two meet.

The test. f and f⁻¹ undo each other when (f ∘ f⁻¹)(x) = x and (f⁻¹ ∘ f)(x) = x, for allowed x. The function that sends x to x is the identity function, id(x) = x.

A worked linear pair. f(x) = 2x + 1, so f⁻¹(x) = (x − 1)/2. Then

  • (f ∘ f⁻¹)(x) = f((x − 1)/2) = 2 · ((x − 1)/2) + 1 = (x − 1) + 1 = x
  • (f⁻¹ ∘ f)(x) = f⁻¹(2x + 1) = ((2x + 1) − 1)/2 = (2x)/2 = x

So in this pair, composition in either order gives the identity. That is what “undo” means here.

A caution already taught. The inverse of a function is not the logic inverse of a statement (the “if not-q then not-p” form). The word inverse still has two jobs in this course; the letters f⁻¹ mark the function job.

Classroom rules stay invented practice functions, not measurements.

Remember

For an invertible f, (f ∘ f⁻¹)(x) = x and (f⁻¹ ∘ f)(x) = x. That common result is the identity, id(x) = x. This inverse is not the logic inverse. Invented practice functions stay labeled.

Key terms: identity function.

Writing & Rhetoric · Franklin’s method: hints from Dryden’s opening

30 min · Method: hints from the set opening, a reconstruction, then a comparison

Key terms

Franklin’s hints, from a short opening
Definition
Franklin’s method, already taught: make brief hints from a model, set the model aside, and reconstruct a sentence of your own from the hints, then compare — without pretending you have memorized a longer extract.
Example
Hints from Dryden’s opening might be: arms; a man; fate; Juno’s hate; driven from the Trojan shore. A reconstruction must be your sentence, then compared with the set lines.
Not this
Not a demand to reproduce Dryden word for word as if that were the only success, and not a license to quote unset lines.
Connects to

Franklin’s method is already in this course: hints, then a reconstruction, then a comparison with the model.

Physics · If the inward pull stops: the tangent direction

50 min · Method: the same circle-and-tangent picture, then Newton’s first law when the centripetal force is removed; no invented speeds

Learn

Key terms

tangent velocity, kept
Definition
The direction the motion already has at a point of the circle: along the tangent. If the inward force stops, this first look says the motion continues in that tangent direction, not along a radius outward.
Example
In the invented string demo, cutting the string leaves the ball to travel along the tangent it had at that instant.
Not this
Not a new outward force, and not a computed distance of travel. We still invent no speed.
Connects to
Monday’s circular motion and centripetal pull, now used on the “what if the pull stops?” question.

Monday named circular motion and a centripetal (center-seeking) force. Today we stay with that picture and press one question: what happens if the inward pull stops?

The velocity at P is along the tangent. The centripetal force was what kept changing that direction. If the force is removed, this first look (using Newton’s first law) says the motion no longer turns inward; it continues in the tangent direction it already had.

We still invent no speed, no string length, and no orbital figure. A sketch of a circle, a point P, a tangent arrow, and an inward arrow that is then taken away is enough.

A radial “fly outward from O along OP” would be a different claim, and it is not the claim this lesson makes.

Remember

If the centripetal force stops, the motion keeps the tangent velocity it already had. That is not a radial flight from the center. No invented speeds.

Key terms: tangent velocity, kept.

Key terms

Flavian
Definition
A later name for the line of Vespasian and his sons Titus and Domitian, who follow the civil war of 69 CE. Like “Julio-Claudian,” it is a later label, not a title we have treated as a founding-day name.
Example
Tacitus’s opening already names Vespasian, Titus, and Domitian together, in the career line used on Monday.
Not this

Atelier · The midtone, and the turn of the sphere

60 min · Method: the same one-lamp sphere, now with slow midtone to turn the form

Learn

Key terms

turn of the form
Definition
The slow change of value as a surface curves away from the light, especially through the midtone into the core shadow, so that the sphere still reads as a solid, not as a flat disk with a stain.
Example
A midtone that darkens gradually into the core shadow helps the sphere turn; a hard cartoon edge in the wrong place flattens it.
Not this
Not a new lamp, and not a demand for a polished finish. The turn can be honest and still unfinished.
Connects to
Monday’s named parts, yesterday’s check, now used on the midtone.

The lamp is still one lamp. Today the work is the turn: the midtone as the sphere curves from the highlight toward the core shadow.

Look more than you draw. If a hard edge appears where the form is still turning, soften only what you see, not as a trick. If the highlight has grown into a smear, it can be reserved or gently cleaned. Do not switch to a cube today. Do not add a second light to “finish” the turn.

Remember

Same lamp, same sphere. Midtone turns the form into the core shadow. No second light, and no new form.

Modern language · Spanish: aquí, ahí, and allí

30 min · Method: three place words, pointed to in the room, with estar. Instruction in English

Learn

Key terms

aquí, ahí, allí
Definition
Three present-tense place words: aquí, here, near the speaker; ahí, there, often a middle distance; allí, over there, farther away.
Example
La regla está aquí. La caja está ahí. El cuaderno está allí.
Not this
Not a new tense, and not a precise measured distance. The three words are a contrast in the room, not a metric scale.
Connects to
Estar for location is already taught. Possessives can sit with them: mi regla está aquí.
Word How to say it Meaning
aquí ah-KEE here (near the speaker)
ahí ah-EE there (a middle distance, often near the person spoken to)
allí ah-YEE there, over there (farther away)
¿Dónde está? DOHN-deh es-TAH Where is it? (you already know estar)

Today’s words place things in the room: aquí (here), ahí (there, a middle distance), allí (over there). Instruction stays in English. The contrast is a pointing contrast, not a measured number of meters.

Original sentences: La regla está aquí. La caja está ahí. El cuaderno está allí. ¿Dónde está mi lápiz? Está aquí.

Decimal place value and planet temperatures stay in the English lessons.

Remember

aquí here; ahí there (middle); allí over there. Used with estar. Not a metric measurement. Instruction in English; Hear for Spanish words.

Art history · A Flavian later name, and a refused invented portrait

30 min · Method: the later-name habit, applied to portrait identification, without inventing a museum object

Learn

Key terms

a later name, in a portrait habit
Definition
The same source habit as in this week’s history: “Flavian” is a later family name. A portrait labeled Vespasian, Titus, or Domitian in a modern catalog is an identification we should treat as a catalog claim, not as a sitting we attended, and not as a dated “style day.”

Not this

Connects to

The work of the sitting is the habit, not a homemade museum.

Remember

Flavian is a later name. A catalog identification is a claim, not a sitting we attended. This lesson invents no bust and no carving year. A later sitting may take a sourced object, labeled as such.

Start from the definition, but do not copy it. If you can only repeat the card, close it and try again from the example you invent.

Hint 2: Near-miss

The "Not this" line on the card names a common mix-up. Explain why that mix-up would change an answer in this lesson.
