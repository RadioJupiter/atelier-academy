A model answer for a near-miss item, so the others can be written in the same shape.

  1. Question: How is a quadratic inequality read from the graph of y = (x − 2)(x − 6), and how is that different from Euclid III.36?
  2. The parabola opens upward. y < 0 between the roots: 2 < x < 6. y > 0 outside the roots.
  3. III.36 is a different picture: from an exterior point, PT² = PA × PB. The 2 and the 6 in the inequality are roots, not automatically a tangent and a secant.
  4. A near-miss is to merge the two pictures, or to treat PT² = PA × PB as a sum, or to invent a complex solution for a square that is never negative.
