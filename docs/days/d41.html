Latin · Review of Capitula I–X: first and second family nouns

40 min · Method: picture-based Latin; original sentences. Instruction in English. A review, not a new chapter.

Learn

Key terms

first-and-second-family nouns
Definition
Nouns whose endings follow the first pattern (often ending in -a in the nominative singular, like puella) or the second (often -us or -um, like hortus). The ending still has to match the job in the sentence.
Example
Puer in hortō est uses puer in the nominative (the one who is) and hortō after in (a place-where form you already have).
Not this
This is not a license to invent a new chapter’s endings, and it is not Capitulum XI. Today only reviews families already used in Capitula I–X.
Connects to
Capitula I–X already used these families in original classroom sentences. Adjectives still match.

Mathematics · Algebra XIII: composition of functions

60 min · Method: a machine picture (first g, then f), then the writing (f ∘ g)(x) = f(g(x)), then a linear example

Learn

Key terms

composition of functions
Definition
The function (f ∘ g) that sends x to f(g(x)): first apply g, then apply f to that result.
Origin
From Middle English composicioun, from Old French composicion, from Latin compositiō (English Wiktionary).
Example
If g(x) = x − 3 and f(x) = 2x + 1, then (f ∘ g)(x) = 2(x − 3) + 1 = 2x − 5, and (f ∘ g)(4) = 3.
Not this
Composition is not multiplication of f and g, and f ∘ g is not generally the same as g ∘ f. The little circle is not a decimal point.
Connects to
Function notation f(x) from Algebra VIII, and linear functions from Algebra IX. The inverse of a linear function (Algebra XII) will return tomorrow’s neighbour, Day 43.
order of composition
Definition
Which function is applied first. In the writing (f ∘ g)(x) = f(g(x)), g is applied first.
Example
With the same f and g as above, (g ∘ f)(x) = (2x + 1) − 3 = 2x − 2, which is not 2x − 5.
Not this
Not “the letters are just a product, so the order cannot matter.” For functions, the order is a different job.
Connects to
The same care as “apply the inner function first” when you already read f(g(x)) without the circle.

A function still assigns one output to each allowed input (Algebra VIII). Today we make a new function by using one function’s output as the next function’s input.

The writing. (f ∘ g)(x) = f(g(x)) . The circle is read “composed with.” It is not a decimal point, and it is not multiplication. The inner function, g, is applied first.

A linear example. Let g(x) = x − 3 and f(x) = 2x + 1. Then (f ∘ g)(x) = f(x − 3) = 2(x − 3) + 1 = 2x − 6 + 1 = 2x − 5. So (f ∘ g)(4) = 2(4) − 5 = 3, which matches f(g(4)) = f(1) = 3.

Order matters. (g ∘ f)(x) = g(2x + 1) = (2x + 1) − 3 = 2x − 2. That is not the same rule as 2x − 5. So f ∘ g and g ∘ f are different functions here.

Classroom numbers stay classroom numbers. These linear rules are invented practice functions, labeled as such; they are not NASA measurements.

Remember

(f ∘ g)(x) = f(g(x)): apply g first. The circle is not multiplication and not a decimal point. f ∘ g is not generally g ∘ f. Invented practice functions stay labeled.

Key terms: composition of functions, order of composition.

Writing & Rhetoric · Because, but, so: a source caution in one sentence

30 min · Method: the stems already taught, now used on a named source, not on a new grammar point

Learn

Key terms

because / but / so, on a source
Definition
The same three stems already taught, now used to keep a source caution in one sentence: a fact *because* of a named source, *but* a limit on what that source is, *so* a careful claim.
Example
Galba, Otho, and Vitellius are named *because* Tacitus names them in the opening of the *Histories*, *but* Tacitus also says his career began under Vespasian, *so* we will not read the year as a simple eyewitness list.
Not this
Not a new kind of conjunction, and not a license to invent a fact the source does not give.
Connects to
Day 1’s because / but / so, and today’s history lesson on the year after 68 CE.

The stems because / but / so were taught in Week 1. Today they carry a source caution, not a new grammar rule.

A model (after the history lesson, or drafted beside it): Tacitus names Galba, Otho, and Vitellius, and he names Vespasian, because those names stand in the opening of the Histories (Loeb translation, 1925, public domain, as on LacusCurtius), but he also writes that his career began under Vespasian, so we will treat him as a later writer with a Flavian career, not as a simple eyewitness of a four-name year.

The but is the limit. The so is the careful claim. No invented quotation, and no invented date inside the sentence.

Remember

Because names the source. But names the limit. So names the careful claim. Do not invent a quotation or a date.

Physics · A first look at circular motion, and a center-seeking force

50 min · Method: a tangent direction, then why a change of direction needs a center-seeking force; no invented speeds

Learn

Key terms

circular motion
Definition
Motion along a circular path. Even if the speed (the distance along the path in each unit of time) is constant, the direction is still changing, so the velocity is changing.
Example
A point moving once around a fixed circle at a steady speed is still changing direction at every moment: the direction is along the tangent.
Not this
Not “constant speed means no change of any kind.” Speed can be constant while direction changes. And not an invented orbital speed for a planet or a spacecraft.
Connects to
Level and week 8’s qualitative look at a curved path, now named as circular motion, still without an invented speed.
centripetal
Definition
Center-seeking: a force (or an acceleration) directed toward the center of the circle, needed if the motion is to stay on that circle.
Example
For a ball on a string, swung in a horizontal circle at a steady speed (an invented classroom demo), the string pulls toward the center. That pull is centripetal.
Not this
Not a second outward force that “balances” it in this first look, and not a license to compute a satellite’s speed. We do not invent a number of newtons for the string, and we do not yet treat a formula as today’s law.
Connects to
Newton’s first law, already in this course: if no net force acted, the motion would not keep turning. A center-seeking force is what turns it.

A path can be curved even when the speed is steady, because direction can still change. Motion around a circle is the clean first case.

Velocity is along the tangent. At each point of the circle, the direction of motion is along the tangent, not along the radius. (You already used a tangent to a circle in geometry; here it is the direction of the motion.)

A change of direction is a change of velocity. So there is an acceleration even when the speed is constant. For motion that stays on the circle, that acceleration is toward the center. A force toward the center is required. The word for that center-seeking direction is centripetal.

A classroom string. A ball on a string, swung in a circle, is an invented demonstration: the string pulls inward. If the string is let go, the ball does not fly radially outward from the center along a radius; it goes off along the tangent it already had. We will not invent a speed, a length of string, or a number of newtons for this picture.

No invented orbital speed. A later, sourced lesson may compute with a named formula. Today is the direction, the name, and the first-law reason.

Remember

Velocity along the tangent. Constant speed can still mean changing velocity. A center-seeking (centripetal) force is required to stay on the circle. No invented orbital speed, and no invented string measurements.

Key terms: circular motion, centripetal.

History · After 68 CE: 69, a later year-name, and Tacitus’s opening

50 min · Method: the already-taught 68 CE end of the Julio-Claudian list, then Tacitus’s opening, with the year-name labeled later

Learn

Key terms

Year of the Four Emperors (later name)
Definition
A later name for the civil-war year 69 CE after Nero’s death in 68 CE, when four men — Galba, Otho, Vitellius, and Vespasian — are usually listed. It is not Tacitus’s own title for the year.
Example
Tacitus’s *Histories* (Loeb translation, 1925, public domain, as printed on LacusCurtius) begins with Galba’s consulship and, in the same opening, names Galba, Otho, and Vitellius, and then Vespasian.
Not this
Not a single “fall of Rome,” and not a claim that the year came already boxed under this modern name. 68 CE ends the Julio-Claudian list already taught; 69 CE is civil war and a new start under Vespasian, not a fall day.
Connects to
Week 8’s Julio-Claudian list through 68 CE, and the habit of labeling later names as later names.
Tacitus as a later source
Definition
Tacitus wrote the *Histories* later than the events of 69 CE. In the opening he says he had no acquaintance with Galba, Otho, or Vitellius through kindness or injury, and he cannot deny that his political career owed its beginning to Vespasian, that Titus advanced it, and that Domitian carried it further.
Example
That career line is why we read him as a later writer with a Flavian career, not as a simple eyewitness roll-call, while still using the names he gives.
Not this
Not a reason to throw the work out, and not a license to invent a different four names. The caution is about how we use the source.
Connects to
Week 8’s habit with later writers (Tacitus, Suetonius) on the Julio-Claudians, now used on the *Histories*.

Week 8 took the Julio-Claudian list through 68 CE and refused a single fall day of Rome. After Nero’s death in that year, 69 CE is a year of civil war. The four men later readers often list are Galba, Otho, Vitellius, and Vespasian. The handy label “Year of the Four Emperors” is a later name, not a title we have from Tacitus for the year.

What Tacitus actually gives, in the opening we can point to. In the Loeb Classical Library translation of the Histories (1925; the text is in the public domain as presented on LacusCurtius), Tacitus begins: “I begin my work with the second consulship of Servius Galba, when Titus Vinius was his colleague.” In the same opening he writes that he had no acquaintance with Galba, Otho, or Vitellius through kindness or injury, and that he “cannot deny that my political career owed its beginning to Vespasian; that Titus advanced it; and that Domitian carried it further.” So the four names of the later year-label are in that opening, together with the two Flavian sons, and together with a career confession.

How we use him. We may use the names. We will also use the confession. We will not treat the passage as a simple eyewitness list, and we will not invent a “fall of Rome” in 69. Vespasian’s success is the start of the Flavian line, which Wednesday will name more carefully.

Source. Tacitus, Histories Book I, opening (Loeb 1925, as on LacusCurtius, Bill Thayer). The year-name “Year of the Four Emperors” is taught as a later label.

Remember

69 CE is a civil-war year after Nero’s death, not a fall of Rome. Galba, Otho, Vitellius, and Vespasian are the four men later readers often list. “Year of the Four Emperors” is a later name. Tacitus’s opening names them and also names his career under Vespasian, Titus, and Domitian.

Atelier · Light on a sphere: highlight, midtone, core shadow

60 min · Method: one sphere, one lamp, named parts of the light; the first sitting of a new simple-form study

Learn

Key terms

light on a simple form
Definition
A first study of how a single, steady light falls on a simple solid (a sphere is today’s form): a highlight, a midtone, a core shadow, and, if the light and the table allow, a cast shadow and a little reflected light.
Example
A pale sphere, or a ball, under one lamp from one side, shows a bright patch on the lit side, a darker belt where the form turns away, and a shadow on the table.
Not this
Not a full still-life, not a second head study, and not a claim that a photograph has already done the looking. Last week’s two-week head critique named a next sitting: simple forms come first, as the Term 1 atelier sequence promised.
Connects to
The value scale and the head studies already taught. Today the form is simpler, so the light can be named more slowly.
core shadow
Definition
The darker belt on the form itself, where the surface turns away from the light, before any light that may bounce back from the table.
Example
On a sphere under one lamp, the core shadow is a curved band, not a flat stain and not the shadow the sphere casts on the table.
Not this
Not the cast shadow (that lies on the table or the wall), and not the highlight (that is on the brightest facing surface).
Connects to
Today’s light on a simple form. Reflected light, if it is seen, sits beside the core shadow, not in place of it.

Last Friday’s atelier critique closed a two-week head and named a next plan. The Term 1 sequence now takes light on simple forms, then a simple cast. This week begins with a sphere (a ball or a pale sphere is enough), under one steady lamp.

Look first. Where is the light? The highlight is the brightest patch on the form. The midtone is the in-between value as the surface turns. The core shadow is the darker belt on the form where it turns away from the light. The cast shadow lies on the table (or the wall), not on the sphere itself. A little reflected light may lift the shadow side if the table sends light back; if you cannot yet see it honestly, do not invent it.

One sitting, one form, one light. Do not add a second lamp to “help.” Do not start a new head. Shade slowly; name each part as you go.

Remember

One sphere, one lamp. Highlight, midtone, core shadow on the form; cast shadow on the table. Do not invent reflected light you cannot see. This is not a new head study.

Key terms: light on a simple form, core shadow.

Modern language · Spanish: possessive adjectives (mi, tu, su, nuestro)

30 min · Method: agreement with the thing owned, then short present-tense sentences. Instruction in English

Learn

Key terms

Spanish possessive adjective
Definition
A word such as mi, tu, su, nuestro, or vuestro that shows who owns something and, in the nuestro / vuestro set, agrees in gender and number with the thing owned, not with the owner. Mi and tu change only for number (mi libro, mis libros).
Example
Mi regla está aquí. Nuestra caja es grande. Sus cuadernos están juntos. (The last may be “his,” “her,” “their,” or a formal “your,” depending on context.)
Not this

Logic · Affirming the consequent, and denying the antecedent

30 min · Method: a conditional already taught, then two invalid moves with the same square-and-rectangle counterexample

Learn

Key terms

affirming the consequent
Definition
An invalid move: from “If P, then Q” and “Q,” to conclude “P.” The consequent Q is affirmed, but that is not enough to give the antecedent P.
Example
If a shape is a square, then it is a rectangle. This shape is a rectangle. Therefore it is a square. — Invalid: a non-square rectangle is still a rectangle.
Not this
Not modus ponens (from “If P, then Q” and “P,” to “Q”), which is valid. And not the undistributed middle (Day 36), which is a different syllogism error. This is a conditional error.
Connects to
Day 21’s converse, inverse, and contrapositive, and Day 16’s necessary and sufficient conditions. Affirming the consequent treats a necessary result as if it were a sufficient test for the start.
denying the antecedent
Definition
An invalid move: from “If P, then Q” and “not P,” to conclude “not Q.” The antecedent is denied, but Q may still hold for another reason.
Example
If a shape is a square, then it is a rectangle. This shape is not a square. Therefore it is not a rectangle. — Invalid: it may still be a non-square rectangle.
Not this
Not modus tollens (from “If P, then Q” and “not Q,” to “not P”), which is valid. The two are easy to mix because both use a “not.”
Connects to
The same conditional, “If P, then Q.” Valid paths: assume P, get Q; or assume not Q, get not P. The two invalid paths are today’s named errors.

Conditionals are already in this course (converse, inverse, contrapositive; necessary and sufficient). Today names two invalid moves that look like reasoning.

Affirming the consequent. From “If P, then Q” and “Q,” it does not follow that P. Example: If a shape is a square, then it is a rectangle. This shape is a rectangle. Therefore it is a square. A non-square rectangle shows the move is invalid.

Denying the antecedent. From “If P, then Q” and “not P,” it does not follow that not Q. Example: If a shape is a square, then it is a rectangle. This shape is not a square. Therefore it is not a rectangle. Again a non-square rectangle is a counterexample.

Valid neighbours, already available. From “If P, then Q” and P, you may conclude Q (a valid path). From “If P, then Q” and not Q, you may conclude not P (modus tollens, the useful “not”). Today’s work is to refuse the two invalid look-alikes, not to invent a new formal calculus.

Classroom shapes stay invented examples, labeled as such.

Remember

From “If P, then Q,” you may not argue from Q to P (affirming the consequent), or from not-P to not-Q (denying the antecedent). A non-square rectangle is a counterexample. These are not modus ponens and not modus tollens.

Key terms: affirming the consequent, denying the antecedent.

Watch me

Show that “If it is a square, then it is a rectangle. It is a rectangle. Therefore it is a square” is invalid.

  1. The form is: If P then Q; Q; therefore P.
  2. That affirms the consequent.
  3. A non-square rectangle is Q without P, so the conclusion need not hold.

Together
