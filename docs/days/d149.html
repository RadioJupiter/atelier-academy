Mathematics · Geometry XC: SSA when the given angle is obtuse, then a mixed practice

40 min · Method: invented obtuse A = 120°, b = 2; no triangle if a ≤ b; one triangle if a > b; then a mix of the week’s acute cases

Learn

Key terms (from earlier lessons)

  • the ambiguous case (SSA) — Day 146

Open a card if you need a reminder; then close it and use the term in your own words.

If the given angle A is obtuse, the height comparison of the acute case is not reused unchanged. In an obtuse triangle the side opposite the obtuse angle is the longest side, so if a ≤ b there is no triangle. If a > b, there is one triangle. On invented figures, A = 120° and b = 2. If a = 2, or if a = 1, then a ≤ b and there is no triangle. If a = 2√3, then a > b. The law of sines gives sin B = 2 × sin 120° / (2√3). Sin 120° = sin(180° − 60°) = sin 60° = √3/2, so sin B = 2 × (√3/2) / (2√3) = 1/2, and B = 30°, the acute value, because A is already obtuse and two obtuse angles cannot stand in one triangle. Then C = 180° − 120° − 30° = 30°, and the triangle is 120°-30°-30°. The figures are invented. Do not invent official measured sides.

A short mix of the acute cases already taught, still with A = 30° and b = 2: a = 1/2, none; a = 1, one right triangle; a = √2, two triangles; a = 2, one isosceles triangle.

Remember

If A is obtuse and a ≤ b, there is no triangle. If a > b, there is one. On invented figures with A = 120° and b = 2, a = 2√3 gives one triangle, 120°-30°-30°.

Watch me

On invented figures with A = 120° and b = 2, what happens if a = 1, and what triangle appears if a = 2√3?

  1. If a = 1, then a < b, so there is no triangle.
  2. If a = 2√3, sin B = 1/2, B = 30°, C = 30°, and the triangle is 120°-30°-30°.
  3. B cannot be 150°, because A is already obtuse. The figures are invented.

Together

On the already-taught acute invented figures A = 30°, b = 2, how many triangles if a = √2, and what are they?

Hint 1: The case

h = 1 and 1 < √2 < 2, so two triangles.

Hint 2: The angles

30°-45°-105° and 30°-135°-15°.

Check

Write in your own words, then look at the key.

  1. If the given angle A is obtuse, when is there no triangle, and when is there one?
  2. On invented figures with A = 120° and b = 2, find the triangle if a = 2√3, and say why B is not 150°.
  3. On invented figures with A = 30° and b = 2, how many triangles if a = 1, if a = √2, and if a = 2?

Exercises

  1. On the obtuse invented figures, what happens if a = 2?
  2. Why is reusing h = b sin A from the acute first look, without the obtuse rule, a miss when A is obtuse?
  3. What official figure must you not invent?

Science · Official Example 20.4: calculating resistance, an automobile headlight

40 min · Method: OpenStax Example 20.4 official arithmetic; 12.0 V, 2.50 A, R = 4.80 Ω; official household voltages reserved

Learn

Key terms (from earlier lessons)

  • Ohm’s law — Day 147

Open a card if you need a reminder; then close it and use the term in your own words.

Official Example 20.4, “Calculating Resistance: An Automobile Headlight,” asks: what is the resistance of an automobile headlight through which 2.50 A flows when 12.0 V is applied to it? From I = V / R, the book rearranges to R = V / I = 12.0 V / 2.50 A = 4.80 Ω. Those are the example’s official figures. The book also notes that this is a relatively small resistance, and that resistance usually increases with temperature, so the bulb has a lower resistance when it is first switched on; that temperature remark is the book’s, not a classroom measurement, and no official cold resistance is invented. The voltage drop across that headlight, V = I R, is the same official 12.0 V. Official household voltages remain reserved. Do not treat Tuesday’s invented 3.00 Ω as if it were this example, and do not invent an official household figure in place of 12.0 V.

Official Example 20.4: 12.0 V and 2.50 A give R = 4.80 Ω. Those figures are official for this example, not Tuesday’s invented check, and not an official household voltage.

Seminar · Economics: saving on invented figures, a first look

40 min · Method: last week’s invented remainder, set aside; distinguished from a tax, a premium, and a deductible; official interest reserved

Learn

Key terms

saving (invented figures)
Definition
Saving, in this invented classroom arrangement, is setting aside some or all of a budget’s remainder, rather than spending it. It is not a tax, not a premium, not a deductible, and not an official interest rate or official account.
Example
On last week’s invented figures, income is $80, expenses are $70, and the remainder is $10. If that $10 is set aside each invented month, three months give 3 × 10 = $30. The figures are invented, not an official wage, rent, or bank product.
Not this
Not the remainder left unplanned, which last week only named. Not a tax, a premium, or a deductible, already taught on invented figures. Not official interest, an official savings rate, or an official account. Not investing as a later first look, which remains reserved if not taught today.
Connects to
Last week’s simple budget on invented figures, and earlier tax, premium, and deductible, also invented. Official interest rates and official accounts remain reserved.

Last week’s invented budget placed income of $80 beside expenses of $70, so the remainder was $10. Today that remainder can be set aside, rather than spent. Saving, in this invented classroom arrangement, is setting aside some or all of the remainder. If the invented $10 is set aside each invented month, three months give 3 × 10 = $30. If only $5 of the remainder is set aside, three months give 3 × 5 = $15, and the other $5 of each remainder has been spent. The $80, the $70, the $10, and the $30 are invented classroom numbers, not an official wage, rent, or bank product.

Saving is not a tax: a tax was a percent taken from invented income, or a percent added to an invented price. It is not a premium, paid in advance on invented insurance. It is not a deductible, borne first only if a named event happens. Official interest rates, official savings products, and official accounts remain reserved. A later first look at investing remains reserved.

Remember

On invented figures, saving is setting aside some or all of a $10 remainder. Three invented months at $10 give $30. The figures are not official, and official interest is not taught today.

Watch me
