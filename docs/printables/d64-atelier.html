Remember

A value pass organizes the whole head into a few values under the fixed light: a clear light, a clear large shadow, and one or two middles. Features, hair, ear, and neck share that light. The large terminator stays. The plate wins.

1. What is a value pass on the head, and what is it not?

2. Why must the hair, the ear, and the neck share the same light as the face?

3. What job does yesterday’s large terminator still do today?

4. If a value and the plate disagree, which wins?

5. Write a three-line note of the values you actually used, named from light to dark.

6. A student outlines a new ear during the value pass. What would you suggest instead?
