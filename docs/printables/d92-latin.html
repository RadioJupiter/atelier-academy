Remember

The present-participle ablative absolute is already taught. Today use it beside main clauses you already have, and contrast it with an ordinary ablative after a preposition. The perfect-participle kind remains reserved.

1. Translate: Puerīs loquentibus, magister tacet.

2. In Magistrō recitante, discipulus ē lūdō ēgreditur, which ablative is the absolute, and which is not?

3. Why is this not a first look at ē plus the ablative?

4. Write two original sentences, each with an ablative absolute, one of them also using a deponent in the main clause.

5. Correct a miss that treats ē lūdō as an absolute, and say why.

6. Why is urbe captā still reserved?

Work in writing. Then mark from the answer key and rework every miss the next day.
