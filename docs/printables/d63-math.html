Remember

If two triangles are similar, corresponding sides are proportional. One known pair gives the scale factor, which finds a missing corresponding side. Match the vertices before writing the fraction.

Key terms: scale factor (similarity).

1. △PQR ∼ △STU, PQ = 6, ST = 9, PR = 10. Find SU.

2. A student writes 4/6 = 10/x for the Learn figure. What has gone wrong, and what is the right proportion?

3. The scale factor from △ABC to △DEF is 3. If BC = 5, what is EF?

4. If the scale factor from △ABC to △DEF is 2/3 and DE = 8, what is AB?
