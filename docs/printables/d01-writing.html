Remember

Kernel first. Expand by answering one question at a time. Keep the same verb unless you have a reason to change it.

1. What is a kernel, in one sentence?

2. Name three questions you can use to expand a kernel.

3. Expand each kernel with at least three question words. Label each addition. (a) The bridge collapsed. (b) The painter scraped the canvas. (c) Prices rose.

4. Complete each stem with because, but and so (nine sentences). Only use facts you are sure of, or check them. (a) Charcoal is used for the first block-in of a drawing … (b) Latin is no longer anyone's first language … (c) A ball thrown straight up slows down as it rises …

5. Rewrite this sentence so that it is precise: The thing in the picture is kind of really interesting because of how it is.

Work in writing. Then mark from the answer key and rework every miss the next day.
