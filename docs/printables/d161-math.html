Remember

If lim f = L and lim g = M, then lim (f + g) = L + M. On the invented functions f(x) = 2x and g(x) = x + 1, as x approaches 3, the limit of the sum is 6 + 4 = 10. Continuity, and a formal epsilon argument, remain reserved.
