Remember

Letter names A–G repeat in each octave. A half step is the distance between adjacent keys; a whole step is two half steps. E–F and B–C are half steps on the white keys. Treble lines E G B D F, spaces F A C E. Bass lines G B D F A, spaces A C E G. Middle C sits on a ledger line between the staves.

Key terms: pitch, clef, staff.

1. Name the treble-clef note on line 1, line 3, line 5, space 2, and space 4.

2. For each of today's key terms (pitch, clef, staff), write one sentence in your own words and one near-miss you must not confuse it with. Then apply one of the terms to a fresh case of your own (not the example on the card).

3. Name the treble-clef note on: line 1, line 3, line 5, space 2, space 4.

4. Name the bass-clef note on: line 1, line 4, space 1, space 3.
