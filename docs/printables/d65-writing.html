Remember

Claim, grounds (data), and warrant form the Toulmin model. Grounds are the same job as Day 8’s evidence. A warrant is a general rule, not a restated claim. Grounds from the set Lincoln sentences must be quoted from those sentences only.

1. In your own words, what are grounds, and what Day 8 word names the same job?

2. Quote the first nine words of the set Bliss extract exactly.

3. Write a warrant for the second set sentence, then write a restated-claim near-miss and label it.

4. Why must later of the address remain unused in the grounds?

5. Write a three-line invented Toulmin plan about a broken pencil point, and label a restated-claim near-miss.

6. Can a warrant be a quotation from the set extract? Explain.

Work in writing. Then mark from the answer key and rework every miss the next day.
