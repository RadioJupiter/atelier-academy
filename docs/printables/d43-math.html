Remember

For an invertible f, (f ∘ f⁻¹)(x) = x and (f⁻¹ ∘ f)(x) = x. That common result is the identity, id(x) = x. This inverse is not the logic inverse. Invented practice functions stay labeled.

Key terms: identity function.

1. f(x) = 3x − 6. Write f⁻¹(x), then find (f ∘ f⁻¹)(x).

2. Why is this “inverse” not the logic inverse of a sentence?

3. For each of today's key terms (identity function), write one sentence in your own words and one near-miss you must not confuse it with. Then apply one of the terms to a fresh case of your own (not the example on the card).

4. g(x) = x/2 + 5. Write g⁻¹(x) and show (g⁻¹ ∘ g)(4) = 4.
