Remember

A proposition is true or false. Connectives: ¬, ∧, ∨ (inclusive), → (false only when p is true and q is false), ↔. From p → q: converse q → p, inverse ¬p → ¬q, contrapositive ¬q → ¬p. Only the contrapositive always matches the original.

Key terms: proposition, conditional, contrapositive.

1. Write the full truth table for p → q. In which row is it false?

2. For each of today's key terms (proposition, conditional, contrapositive), write one sentence in your own words and one near-miss you must not confuse it with. Then apply one of the terms to a fresh case of your own (not the example on the card).

3. Write the full truth table for p → q and for ¬p ∨ q. What do you notice?

4. Statement: "If a shape is a square, then it has four sides." Write its converse, inverse and contrapositive, and mark each true or false.

Work in writing. Then mark from the answer key and rework every miss the next day.
