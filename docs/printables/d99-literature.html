Remember

Limbo is named at IV.45 as the first circle. A Mighty One, with sign of victory incoronate, drew forth the First Parent, Abel, Noah, Moses, Abraham, David, Israel, Rachel, and others; earlier than these, none were saved. Homer, Horace, Ovid, and Lucan approach, and “the sixth was I, ’mid so much wit.” Keep “a Mighty One” as the set wording. The later catalog remains reserved.

Key terms: Limbo (Inferno IV), the four poets, and “the sixth was I” (Inferno IV).

1. Where is Limbo named, and what is it the set name for?

2. What does the Mighty One have, in the set wording, and whom does the guide name among those drawn forth?

3. Who are the four poets, and what is the set wording of the speaker’s place among them?

4. Why must a later identification of the Mighty One not be imported as if it were in these lines?
