Remember

For x² + bx + c = 0, sum of roots = −b, product = c. For ax² + bx + c = 0, sum = −b/a, product = c/a. This lesson uses two real roots (possibly repeated). The minus sign on the sum matters.

Key terms: Vieta’s formulas (quadratic).

1. A monic quadratic has roots −1 and 4. Write the quadratic as x² + bx + c and name b and c.

2. For x² + 6x + 9 = 0, give the sum and the product, and say what is special about the roots.

3. For each of today's key terms (Vieta’s formulas (quadratic)), write one sentence in your own words and one near-miss you must not confuse it with. Then apply one of the terms to a fresh case of your own (not the example on the card).

4. Why is “the sum of the roots of x² + bx + c = 0 is b” a near-miss?
