Damping removes mechanical energy: Wnc = Δ(KE + PE), and Wnc is negative. Underdamped, critically damped, and overdamped, as OpenStax defines them. Example 16.7: f = 0.157 N, d = 1.59 m, underdamped; a force 20 times greater moves the object only 0.0484 m, a sourced contrast. Invented cases stay labeled invented. Section 16.8 is reserved.
