Remember

From If P then Q: converse If Q then P; inverse If not P then not Q; contrapositive If not Q then not P. Only the contrapositive is equivalent to the original.

Key terms: converse, inverse, contrapositive.

1. For “If it is raining, then the street is wet,” write the converse and say whether the converse must be true if the original is true.

2. Which two of the four statements (original, converse, inverse, contrapositive) are equivalent to each other but not necessarily to the other pair?

3. For each of today's key terms (converse, inverse, contrapositive), write one sentence in your own words and one near-miss you must not confuse it with. Then apply one of the terms to a fresh case of your own (not the example on the card).

4. Form all three related conditionals of: If ABCD is cyclic, then opposite angles sum to 180°.
