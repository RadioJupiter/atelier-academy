Remember

If lim f = L and lim g = M, and M ≠ 0, then lim (f / g) = L / M. On the invented functions f(x) = 2x and g(x) = x + 1, as x approaches 3, the limit of the quotient is 3/2. If M = 0, the rule does not apply.

1. What is the limit of a quotient, in this first look, and when does the rule not apply?

2. On the invented functions f(x) = 2x and g(x) = x + 1, as x approaches 3, what is lim (f / g)?

3. Why is last week’s (x² − 4)/(x − 2) not an instance of today’s rule?
