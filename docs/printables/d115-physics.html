A wave is a disturbance that propagates. vw = λ / T = fλ. Example 16.8: λ = 10.0 m, T = 5.00 s, vw = 2.00 m/s. Transverse: disturbance perpendicular to propagation. Longitudinal: disturbance parallel to propagation.

2. Recompute Example 16.8. Why is the gull’s up-and-down speed a miss?

3. Give one transverse example and one longitudinal example from OpenStax 16.9.
