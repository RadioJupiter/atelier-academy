Remember

Ponens: If P then Q; P; therefore Q. Tollens: If P then Q; not Q; therefore not P. Disjunctive syllogism: P or Q; not P; therefore Q. Default “or” is inclusive. Not affirming the consequent.

1. State modus ponens, and give last week’s square-and-rectangle instance.

2. State modus tollens, and say how it differs from denying the antecedent.

3. Why is “it is a rectangle; therefore it is a square” not modus ponens?

4. Give a fresh “or” pair and apply disjunctive syllogism in one direction.
