Remember

Post hoc treats a later event as caused by an earlier one only because it came after. Sequence alone is not a cause. Invented examples are labeled invented.

Key terms: post hoc.

1. Rewrite the invented bell-and-rain claim so that it no longer treats sequence as a cause (you may simply refuse the cause).

2. Why is ‘after this’ not enough for ‘because of this’?

3. For each of today's key terms (post hoc), write one sentence in your own words and one near-miss you must not confuse it with. Then apply one of the terms to a fresh case of your own (not the example on the card).

4. Invent one short post hoc argument, label it invented, and name the earlier event and the later event.
