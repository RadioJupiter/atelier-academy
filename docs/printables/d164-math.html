Remember

lim (f + g) = L + M, lim (f g) = L M, and, if M ≠ 0, lim (f / g) = L / M. On the invented functions as x approaches 3, those results are 10, 24, and 3/2. If M = 0, the quotient rule does not apply.

1. State the three rules, including the condition on the quotient.

2. On the invented f(x) = 2x and g(x) = x + 1, as x approaches 3, what are lim (f + g), lim (f g), and lim (f / g)?

3. When does the quotient rule not apply?

4. On invented functions u(x) = x and v(x) = 4, as x approaches 5, find the three limits.

5. On invented p(x) = 3x and q(x) = x − 2, as x approaches 2, what are lim (p + q) and lim (p q), and why is lim (p / q) not given by today’s quotient rule?
