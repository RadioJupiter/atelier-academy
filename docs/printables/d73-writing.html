Remember

A false dilemma presents two options as if they were the only ones, when another genuine option has been left out. A genuine exhaustive either–or is not a fallacy.

Key terms: false dilemma.

1. Why is “either right-angled or not right-angled” not, by itself, a false dilemma?

2. Rewrite the invented 3-4-5 sentence so that it no longer hides a third case.

3. For each of today's key terms (false dilemma), write one sentence in your own words and one near-miss you must not confuse it with. Then apply one of the terms to a fresh case of your own (not the example on the card).

4. Invent (and label invented) a false dilemma about solutions or about Roman months, then name the option that was left out.
