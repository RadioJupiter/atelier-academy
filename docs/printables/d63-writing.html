Writing & Rhetoric · A warrant is not a restated claim

Remember

A warrant is a general rule that joins grounds to a claim. A restated claim says the claim again (often after “therefore” or “so”) and does not do that job. You can test a warrant by asking whether it is a rule someone could dispute.

1. Claim: the path is icy. Grounds: it shines and is slippery. Which is a warrant: (A) “icy paths shine and are slippery,” or (B) “therefore the path is icy”?

2. Why can a warrant be disagreed with, while a restated claim usually cannot in the same way?

3. Using only the set Lincoln sentence, write a warrant that is not a restated claim.

4. A student writes the whole second sentence again as the warrant. What is missing?

5. Invent a three-part argument about a lit fireplace. Then add a fourth sentence that is a restated claim, and label it as such.

6. Repair this warrant: “so Lincoln is right.”
