Remember

An argument is valid if the conclusion must be true whenever the premises are. It is sound if it is valid and the premises are actually true. Valid forms: modus ponens, modus tollens. Invalid: affirming the consequent, denying the antecedent. Validity is about form, not about whether you like the conclusion.

Key terms: validity, soundness, fallacy.

1. Name the form and say if it is valid: 'If it rains, the match is cancelled. It did not rain. So the match was not cancelled.'

2. For each of today's key terms (validity, soundness, fallacy), write one sentence in your own words and one near-miss you must not confuse it with. Then apply one of the terms to a fresh case of your own (not the example on the card).

3. Name the form and say if it is valid: (a) If the plate is accurate, the proportions match. The proportions match. So the plate is accurate. (b) If a triangle is equilateral, it is isosceles. This triangle is not isosceles. So it is not equilateral. (c) If it rains, the match is cancelled. It did not rain. So the match was not cancelled.

4. Give an example of a valid argument with a false conclusion. What must be true of it?
