Remember

Haya means that there be, in these first-look frames. It is not hay, not sea, and not vaya.

1. Give the six present-subjunctive forms of haber.

2. Choose: “Espero que ustedes ___ (vayan / hayan / van) al mercado,” if the verb is ir.

3. Why is “sea silencio” a miss for “that there be silence,” in this week’s haber frame?

4. Write one invented sentence each for haya, sea, and hable.

5. What is the near-miss if someone writes “hay” after “espero que,” and if someone writes “vaya” for “that there be”?

6. What remains reserved?

Work in writing. Then mark from the answer key and rework every miss the next day.
