Remember

The church called Sophia is read here from Procopius, I.1.20–22: burned, then rebuilt by Justinian “so finely shaped.” The source is a verbal description, not a plan or a photograph. No height or span is invented.

Key terms: a building described in words.

1. What does a “building described in words” give you that a photograph, if this course had set one, would not, and what does it not give you?

2. Why is Procopius’s comparison (that people would have prayed to see the old church destroyed) not the same as a measured plan?

3. For each of today's key terms (a building described in words), write one sentence in your own words and one near-miss you must not confuse it with. Then apply one of the terms to a fresh case of your own (not the example on the card).

4. This sitting does not add a later sentence of the chapter as if it were already set.
