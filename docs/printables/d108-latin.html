Remember

Present: loquor. Perfect: locūtus sum, with sum. Present-participle absolute: same time, no sum. Perfect-participle absolute: already complete, no sum. Do not merge the four.

1. Translate Ego locūtus sum and Ego loquor, and name each tense.

2. Translate Magistrō recitante, puerī silent, and name the time.

3. Translate Urbe captā, agricolae fugiunt, and name the time.

4. Why must you not treat puerō locūtō as a perfect tense with sum?
