Remember

Halftones belong to the light family. They stay lighter than the terminator's shadow side. Add them late, in a few planes, and check by squinting.

1. Which family do halftones belong to?

2. Why must a halftone stay lighter than the shadow?

3. (70 min) Model the halftones. Before each area, name its value number aloud.

4. (20 min) Compare the drawing and the cast at the same time from the marked spot, squinting. List any area whose value is off by more than one step.

Work in writing. Then mark from the answer key and rework every miss the next day.
