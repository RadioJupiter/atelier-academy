Remember

A précis is shorter, in your own words, true to the set extract, and attributed. It is not a quotation, and not a later chapter.

1. How is a précis different from yesterday’s quotation?

2. Write the attribution that belongs under your précis.

4. Why is an unattributed précis a miss?
