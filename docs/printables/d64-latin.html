Remember

After putō or dīcō, esse takes an accusative subject, and a predicate adjective is also accusative: Putō corpus sānum esse. This is not the same as Corpus sānum est.

Key terms: AcI with esse.

2. Write Latin for “I think that the heart is healthy.”

3. Correct: *Dīcō caput magnus esse.
