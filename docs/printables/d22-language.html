Remember

estar + -ando / -iendo presents an action in progress. Not estar + infinitive. leer → leyendo; pedir → pidiendo. This is still a present-tense form, not a past.

Key terms: present progressive, present participle (-ando / -iendo).

1. Give the present participle of hablar, comer, and pedir.

2. Write: “She is serving the food.”

3. For each of today's key terms (present progressive, present participle (-ando / -iendo)), write one sentence in your own words and one near-miss you must not confuse it with. Then apply one of the terms to a fresh case of your own (not the example on the card).

4. Conjugate estar leyendo for yo, tú, and nosotros.

Work in writing. Then mark from the answer key and rework every miss the next day.
