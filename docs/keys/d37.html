Latin · Capitulum X, part 2: the present infinitive, active

Check. 1. habēre; esse; īre. 2. Homō īre potest. Potes canem habēre. 3. Model: present infinitive (active). Own words should match this idea: The ‘to …’ form of the verb, not limited to a person in the way a finite form is. From Late Latin īnfīnītīvus (‘unlimited, indefinite’), from Latin īnfīnītus (‘unlimited, infinite’). In this lesson the present active infinitives include vocāre, habēre, vidēre, esse, and īre. Near-miss: Not a new tense of the finite verb, and not an English ‘ing’ form. vidēre is ‘to see,’ not ‘sees’ and not ‘seeing’ as a main verb. posse + infinitive. Own words should match this idea: posse means ‘to be able / can.’ In this first look we use possum (I am able), potes (you are able), and potest (he/she is able), followed by a present active infinitive. Near-miss: Not *potest videt (a finite form after potest), and not *possum videō. After posse, the second verb is an infinitive. The fresh case should use the term correctly and not be copied from the card.

  1. The person is already on potest; the infinitive names the action.
  2. A new correct sentence with both forms.
  3. A short, correct three-sentence string.
  4. *potest videt (or similar) is the near-miss; write potest + infinitive.
  5. A complete copied set.

Mathematics · Geometry XVIII: regular polygons, and the interior angle

Check. 1. ((8 − 2)/8)×180° = (6/8)×180° = 135°. 2. n = 360°/40° = 9 sides; each interior = 180° − 40° = 140° (or ((7)/9)×180° = 140°). 3. Model: regular polygon. Own words should match this idea: A polygon with all sides equal and all interior angles equal. The name polygon comes from Greek πολύγωνον (polugōnon), from πολύς (polus), “many,” and γωνία (gōnia), “angle.” Near-miss: Not “any hexagon,” and not a circle (a circle is not a polygon). A rectangle that is not a square has equal angles but not all sides equal, so it is not regular. The fresh case should use the term correctly and not be copied from the card.

  1. From one vertex a heptagon divides into 5 triangles; 5×180° = 900°.
  2. Yes, in this course: all sides equal already forces all angles equal in a triangle, so an equilateral triangle is regular.
  3. The sides are not all equal (or: it has equal angles, but regular requires equal sides as well).
  4. A drawing with 6 − 2 = 4 triangles from one vertex.
  5. A fair set: the sum is (n − 2)×180°, because the polygon divides into n − 2 triangles; but 120° is the regular-hexagon case, so a non-regular hexagon is not forced to that angle.

Science · The lens changes shape: accommodation

Check. 1. A near page (more rounded). 2. Cornea, pupil, lens (accommodation here), retina. 3. Model: accommodation (eye). Own words should match this idea: The change of shape of the eye’s lens that allows a near object, or a far object, to be focused on the retina. When the lens becomes more rounded, the eye is set for a nearer object; when it flattens, for a farther one (in this first look). Near-miss: Not a change of the cornea’s place, and not a new retina. The cornea still does much of the bending of light (Day 32); the lens makes a further, adjustable change. The fresh case should use the term correctly and not be copied from the card.

  1. This class has no sourced measurement to teach; a number would be an invention.
  2. An image is formed, and a signal can begin (Day 34). Accommodation does not replace the retina.
  3. A short paragraph that keeps that promise.
  4. Likeness: a focus that can be changed. Unlikeness: a living lens that changes shape, not (in this lesson) a barrel that slides.
  5. A fair set: the cornea still begins the bending of light; but accommodation is a change of the lens, so near and far are not the same lens shape.

Modern language · Spanish: the weather, in the present

Check. 1. For example: Hace sol. No hace viento. 2. Está nublado. Hay nubes. 3. Model: weather in the present. Own words should match this idea: Present-tense patterns for the weather: hace + a weather noun or adjective in set phrases (hace frío, hace calor, hace viento, hace sol); está + an adjective (está nublado, está despejado); and hay + a noun (hay niebla, hay nubes). The subject is not a person in these set phrases. Near-miss: Not es frío for the weather (that would describe a thing as ‘a cold thing’ in a different sentence), and not a past tense (hizo frío is not today’s form). And not *hace nublado: nublado takes está. The fresh case should use the term correctly and not be copied from the card.

  1. Nublado is an adjective with está; frío in this set phrase goes with hace. The two patterns are not interchangeable.
  2. Es el 5 de mayo is a date; Hace frío (or Está nublado) is the weather. Different jobs.
  3. Two heard patterns, each in a correct new sentence.
  4. A short, correct three-sentence string.
  5. Hace viento, y hay nubes.

Music theory · Interval inversion, with the octave as the frame

Check. 1. A perfect fifth (4 + 5 = 9; perfect stays perfect). A major sixth (a minor third inverts to a major sixth). 2. Each pair of partners fills an octave (the eight letter names from a note to its octave). 3. Model: interval inversion. Own words should match this idea: The partner of an interval when one of the two notes is moved by an octave, so that the old top note is now below, or the old bottom note is now above. In this first look, the interval numbers add to nine (a third inverts to a sixth, a fifth to a fourth), and a perfect interval inverts to a perfect interval, while a major interval inverts to a minor interval. Near-miss: Not a claim that the two intervals sound the same, and not a new meaning of “inverse” from yesterday’s mathematics or from the logic inverse. And not a full table of augmented and diminished inversions today. octave as a frame. Own words should match this idea: The octave (from Latin octavus, “eighth”) is the interval of eight letter names, inclusive, for example C to the next C. In this lesson it is the frame that interval inversion fills: a fifth plus the fourth that inverts it make an octave. Near-miss: Not a new scale, and not a claim that “eighth” is a count of steps beyond C. The count is inclusive, as already taught. The fresh case should use the term correctly and not be copied from the card.

  1. Here it names a music operation on an interval; f⁻¹ undoes a function; the logic inverse changes a conditional. Three uses of a word, labeled.
  2. G–D is a perfect fifth; its inversion is a perfect fourth, D–G (or D up to the next G, depending on which note was moved).
  3. The wider fifth and the remaining fourth, correctly labeled, filling an octave.
  4. A fair set: the numbers add to nine, because each count includes a shared endpoint; but the two intervals are not the same size or sound, so inversion is a pairing, not an identity.
  5. A complete copied reminder.
