Writing & Rhetoric · The sentence: kernels and expansion

Writing has no single correct answer; check against these criteria and models.

  1. Criteria: the kernel is still the grammatical core; each addition answers its labelled question; the sentence is one sentence with correct punctuation. Model (a): During the spring flood of 1888 [when], the wooden bridge over the river [where] collapsed under the weight of debris [why/how]. (Invented example: mark it as invented if you write one.)
  2. Models: (a) … because it is easy to erase and adjust; … but it smudges unless fixed or handled carefully; … so the artist can find the large shapes quickly before committing to detail. (b) … because no community speaks it natively today; … but it remains the official language of the Holy See; … so it is learned through texts rather than by immersion in a living community. (c) … because gravity accelerates it downward the whole time; … but it is still moving upward until the very top; … so its speed at the top is momentarily zero.
  3. Any precise version names the thing, the quality and the reason, e.g. The cracked varnish in the upper left corner draws the eye because it breaks the otherwise smooth surface of the sky.

Logic · Propositions and truth tables

  1. Rows (p, q): TT → T, TF → F, FT → T, FF → T for both. The columns are identical: p → q is logically equivalent to ¬p ∨ q.
  2. Converse: "If it has four sides, it is a square": false (a rectangle). Inverse: "If it is not a square, it does not have four sides": false. Contrapositive: "If it does not have four sides, it is not a square": true.
  3. p is T, q is F. p ∧ q = F; p ∨ q = T; p → q = F (T → F); q → p = T (F → anything); ¬q → p = T → T = T.
