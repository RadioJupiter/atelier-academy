Mathematics · Algebra XIV: composition and the inverse

Check. 1. f⁻¹(x) = (x + 6)/3; (f ∘ f⁻¹)(x) = x. 2. The logic inverse is a statement of the form “if not q, then not p.” Here inverse means a function that undoes f. 3. Model: identity function. Own words should match this idea: The function that sends every allowed x to x itself, often written id(x) = x. It is the result of composing a function with its inverse, when that inverse exists. Near-miss: Not the logic inverse of a statement (Day 21 / Day 39). And not “multiply by 1” as a claim about a different function f; the identity is its own function, id(x) = x. The fresh case should use the term correctly and not be copied from the card.

  1. g⁻¹(x) = 2(x − 5); g(4) = 7, and g⁻¹(7) = 2(2) = 4, so (g⁻¹ ∘ g)(4) = 4.
  2. h⁻¹(x) = 5 − x, the same rule; (h ∘ h)(x) = 5 − (5 − x) = x. So h is its own inverse.
  3. No. Multiplying some function f by 1 still gives f, not id, unless f already was id. The identity is the function whose output is the input.
  4. p⁻¹(x) = x/4; (p ∘ p⁻¹)(10) = 10. Invented pair.
  5. If m = 0, f is a constant function, and many inputs share one output, so no inverse function exists.

History · A later name: the Flavian line

Check. 1. Vespasian, Titus, and Domitian. 2. Year of the Four Emperors. 3. Model: Flavian. Own words should match this idea: A later name for the line of Vespasian and his sons Titus and Domitian, who follow the civil war of 69 CE. Like “Julio-Claudian,” it is a later label, not a title we have treated as a founding-day name. Near-miss: Not a second founding of Rome, not a fall day, and not a claim that people in 69 CE walked about already using our later textbook name as their everyday political heading. The fresh case should use the term correctly and not be copied from the card.

  3. A later family-name is labeled as a later name, and no single fall day is invented.
  4. The principate continues under a new line; Rome is not being taught as ended in 69.
