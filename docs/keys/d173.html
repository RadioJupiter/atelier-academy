Mathematics · The derivative of invented f(x) = x²

Check. 1. [ (x + h)² − x² ] / h = 2x + h, for h ≠ 0, and the limit is 2x. 2. 2 × 3 = 6, and 2 × 0 = 0, matching yesterday’s limits. 3. f'(4) = 8, and f'(10) = 20. 4. Model: the derivative of invented f(x) = x². Own words should match this idea: On the invented function f(x) = x², the difference quotient at a general x is [ (x + h)² − x² ] / h = (x² + 2xh + h² − x²) / h = 2x + h, for h ≠ 0. The derivative function is the limit as h approaches 0: f'(x) = lim h→0 (2x + h) = 2x. This agrees with yesterday’s point values: f'(3) = 6, f'(2) = 4, f'(1) = 2, and f'(0) = 0. The function is invented. A formal epsilon argument remains reserved. Derivatives of other functions remain reserved. Near-miss: Not yesterday’s two point values as if the general rule had already been proved. Not a formal epsilon argument. Not a derivative of a different function, which remains reserved. Not ∞ treated as a number to substitute. The fresh case should use the term correctly and not be copied from the card.

Exercises. 1. f'(6) = 12, and f'(1/2) = 1. 2. Only f(x) = x² has been computed. A derivative of another function remains reserved until it is taught as its own first look.

Own words should match this idea: OpenStax 25.4, after the official critical angles, describes fiber optics qualitatively: light can be guided along a transparent fiber by already-taught total internal reflection, remaining inside the fiber so long as it strikes the boundary at an angle greater than the critical angle.
