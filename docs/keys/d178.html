Mathematics · Limits, reviewed

Check. 1. A value that a quantity approaches as an input approaches a chosen number. The limit is 6. 2. The limit is about nearby values, not about a required value at the point itself. The limit is 4, by factorization. 3. 10, 24, and 3/2.

Exercises. 1. The limit of the denominator is 0, so that rule does not apply. The limit 4 was found by factorization. 2. Lim (p + q) = 6 + 1 = 7, and lim (p / q) = 6/1 = 6.
