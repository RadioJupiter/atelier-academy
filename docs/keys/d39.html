Latin · Capitulum X, part 4: nouns and infinitives together

Check. 1. Homō rēgem vidēre potest. Rēx vocārī potest. 2. pedem; hominem. For example: Potes pedem vidēre. 3. Model: nouns with an infinitive. Own words should match this idea: A mix, not a new ending: today’s sentences combine a third-declension noun (homō, leō, pēs, or last week’s rēx, vōx, canis) with posse + an active or passive infinitive. Near-miss: Not a new case, and not a finite passive. Keep the accusative for the object of an active infinitive (leōnem vidēre), and do not put that object on a passive infinitive as if it were still the object of ‘to see.’ The fresh case should use the term correctly and not be copied from the card.

  1. Two new correct sentences, each using the form that the sentence actually needs.
  2. After potest you need an infinitive (not videt), and the object of vidēre is accusative (leōnem).
  3. A short, correct four-sentence string.
  4. ped-; leōn-.
  5. Two labeled models.

Mathematics · Algebra XII: the inverse of a linear function

Check. 1. h⁻¹(x) = 4 − x, or (x − 4)/(−1). Check: h(h⁻¹(x)) = −(4 − x) + 4 = −4 + x + 4 = x. 2. f⁻¹(0) = 2, because (0 + 6)/3 = 2. It is the input that f sends to 0 (the x-intercept of f, recovered as an output of f⁻¹). 3. Model: inverse of a linear function. Own words should match this idea: The function that undoes a given linear function. If f(x) = mx + b with m ≠ 0, the inverse is f⁻¹(x) = (x − b)/m. The notation f⁻¹ is not a power; it names the inverse function. The word inverse here is from Latin inversus, from invertere, “to turn.” Near-miss: Not the logic inverse of a conditional (Day 21: the inverse of “If P, then Q” is “If not P, then not Q”). And not 1/f(x), the reciprocal. And not an inverse for a quadratic in this lesson (a quadratic is not one-to-one on the whole line). The fresh case should use the term correctly and not be copied from the card.

  1. f⁻¹(5) = 2, because the inverse sends each output back to its input.
  2. k⁻¹(x) = 2x; m = 1/2, b = 0.
  3. The two points are reflections of each other across y = x: input and output have changed places.
  4. f⁻¹ names the inverse function, not the reciprocal. 1/f(x) is a different rule.
  5. A fair set: it has an inverse, because each output comes from exactly one input and the operations can be undone; but “inverse” also names a transformation of a conditional, so the two uses must be labeled.

Modern language · Spanish: object pronouns with two verbs

Check. 1. Lo tenemos que practicar. Tenemos que practicarlo. 2. For example: ¿Lo vas a leer? or ¿Vas a leerlo? 3. Model: pronouns with two verbs. Own words should match this idea: When a conjugated verb is followed by an infinitive (ir a, tener que, acabar de, and similar), a direct- or indirect-object pronoun may attach to the infinitive or stand before the conjugated verb. Both are correct in this lesson: Lo voy a ver. Voy a verlo. Near-miss: Not a drop of the pronoun, and not a new past tense. Do not write *Voy a lo ver (the pronoun is not placed between a and the infinitive in that way). And the two options are alternatives, not two different meanings today. The fresh case should use the term correctly and not be copied from the card.

  1. They are two correct places for the same object pronoun, with the same meaning today.
  2. Two new sentences, one of each placement.
  3. A short, correct four-sentence string (two labeled pairs).
  4. Tengo que pedirlo, or Lo tengo que pedir.
  5. Lo acaba de pedir. Acaba de pedirlo.
