Mathematics · Geometry XC: SSA when the given angle is obtuse, then a mixed practice

Check. 1. If a ≤ b, there is no triangle. If a > b, there is one triangle. 2. Sin B = 1/2, so B = 30°, C = 30°, and the triangle is 120°-30°-30°. B is not 150°, because A is already obtuse. 3. If a = 1, one right triangle. If a = √2, two triangles, 30°-45°-105° and 30°-135°-15°. If a = 2, one isosceles triangle, 30°-30°-120°.

Exercises. 1. a = b, so there is no triangle, because A is obtuse and a is not greater than b. 2. The acute height test is not the whole of the obtuse rule. When A is obtuse, the opposite side must be the longest, so a must be greater than b. 3. Do not invent official measured sides or official counted triangles in a real figure.

Writing · A tighter original confirmation: one claim, fewer wasted words

Check. 1. A fair answer states one claim clearly and gives one direct already-taught reason, in two or three sentences, with no wasted opening. 2. “It is interesting that,” or “everyone knows that,” names no reason and confirms nothing. 3. Not a refutation, not a new first look, not a living person, and not an official handbook quotation.

Exercises. 1. A fair tighter version keeps the claim and the reason and drops only what does not help. 2. A maxim is a short precept, not a reasoned defense of a stated claim. 3. A longer later elaboration remains reserved.

Science · Official Example 20.4: calculating resistance, an automobile headlight

Check. 1. R = 4.80 Ω, from R = V / I = 12.0 / 2.50. 2. V = 12.0 V, the same official applied voltage, as I R. 3. Tuesday’s figures were invented. Official household voltages remain reserved, and 120 V is not this example’s official 12.0 V.

Exercises. 1. 12.0 / 2.50 = 4.80. 2. The book says resistance usually increases with temperature, so the bulb has a lower resistance when first switched on. No official cold resistance is invented. 3. Official household voltages, drift velocity, and resistivity remain reserved.

Literature · Pride and Prejudice, Chapter 6: “a pair of fine eyes,” and Miss Elizabeth Bennet

Check. 1. Chapter 7 remains reserved. Official identifications of characters with living people, and official advice, are not added.

Seminar · Economics: saving on invented figures, a first look

Check. 1. Setting aside some or all of a budget’s remainder, rather than spending it. 3 × 10 = $30. 2. 3 × 5 = $15 is set aside, and the other $5 of each remainder has been spent. The figures are invented. 3. A tax is a percent taken or added. A premium is paid in advance. A deductible is borne first only if a named event happens. Official interest rates remain reserved, so no official interest is added to the $30. 4. Model: saving (invented figures). Own words should match this idea: Saving, in this invented classroom arrangement, is setting aside some or all of a budget’s remainder, rather than spending it. It is not a tax, not a premium, not a deductible, and not an official interest rate or official account. Near-miss: Not the remainder left unplanned, which last week only named. Not a tax, a premium, or a deductible, already taught on invented figures. Not official interest, an official savings rate, or an official account. Not investing as a later first look, which remains reserved if not taught today. The fresh case should use the term correctly and not be copied from the card.

Exercises. 1. 4 × 10 = $40, still invented. 2. Last week named income, expenses, and a remainder. Today that remainder can be set aside, which is saving in this invented arrangement. 3. Official interest rates, official savings products, official accounts, and a later first look at investing remain reserved.
