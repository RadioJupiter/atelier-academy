Latin · A tighter mix, with ēgredior as well as sequor

Mathematics · The derivative at a point, a first look

Check. 1. f'(a) = lim h→0 [f(a + h) − f(a)] / h, when the limit exists. 2. f'(3) = lim (6 + h) = 6. f'(2) = lim (4 + h) = 4. 3. Only two points have been computed. The general calculation at an arbitrary x waits until tomorrow. 4. Model: the derivative at a point, a first look. Own words should match this idea: The derivative of a function f at a number a, written f'(a), is, in this first look, the limit of the already-taught difference quotient as h approaches 0, when that limit exists: f'(a) = lim h→0 [f(a + h) − f(a)] / h. On the invented function f(x) = x², the difference quotient at 3 simplifies to 6 + h, so f'(3) = lim h→0 (6 + h) = 6. At 2, the difference quotient simplifies to 4 + h, so f'(2) = 4. The English noun derivative is from Middle French dérivatif, from Latin dērīvātus, the perfect passive participle of dērīvō, “to derive,” as given on Wiktionary. The function and the chosen numbers are invented. A formal epsilon argument remains reserved. The derivative as a function of x waits until tomorrow. Near-miss: Not yesterday’s difference quotient as if the limit had already been taken. Not a formal epsilon argument. Not ∞ treated as a number to substitute. Not the general derivative function, which waits until tomorrow. Not a claim about official data. The fresh case should use the term correctly and not be copied from the card.

Exercises. 1. [ (1 + h)² − 1 ] / h = (1 + 2h + h² − 1) / h = 2 + h, so f'(1) = 2. 2. Infinity is not a number to substitute. The limit describes what the quotient approaches as h approaches 0.

Science · Official Example 20.8, the book’s example cost of a 60-W bulb

Check. 1. E = 60.0 kWh; electricity $7.20; total $7.45, official book figures. 2. It is the book’s example rate, not a named utility rate. 3. Part (b), on a compact fluorescent light, is Thursday’s official job. 4. Model: official Example 20.8, the book’s example cost of a 60-W bulb. Own words should match this idea: OpenStax official Example 20.8 uses a book example rate of 12 cents per kWh, not a named utility rate, and asks for the total cost of using a 60-W incandescent bulb for 1000 hours if the bulb cost 25 cents. The official arithmetic is E = P t = (60 W)(1000 h) = 60,000 W·h = 60.0 kWh, then cost = (60.0 kWh)($0.12/kWh) = $7.20, and the total, including the 25-cent bulb, is $7.45 for 1000 hours. Those figures are official book example figures, not a real named utility bill. Part (b), on a compact fluorescent light, waits until Thursday. Near-miss: Not last week’s official 170 V or 120 W as if they had already given a cost. Not a named utility rate treated as official here. Not part (b) of official Example 20.8, which waits until Thursday. Not invented official rates. The fresh case should use the term correctly and not be copied from the card.

Exercises. 1. 60,000 W·h = 60.0 kWh, because 1 kWh = 1000 W·h. 60.0 × 0.12 = 7.20. 2. Official 170 V was the peak voltage in official Example 20.9, a different official job.
