Latin · Cases as jobs (Capitula I–X)

Check. 1. puella is the subject (nominative). rosam is the object (accusative). 2. The object, the thing given, is rosam (accusative). puellae is the person to whom (dative).

  2. Puer puellae rosam dat.
  3. A labeled copy of a model sentence.

Mathematics · A quadratic inequality, from the graph

Check. 1. 4 < x < 10. 2. No real solution. A square is never negative; it is 0 only at x = 3.

  1. x ≤ 2 or x ≥ 8 (include the roots, where the expression is 0).
  2. The downward-opening companion is below the axis outside the roots: x < 2 or x > 8.
  3. III.36 is a tangent and a secant from an exterior point — a different picture. The 2 and the 8 here are roots, not automatically PA and PB.

Writing & Rhetoric · Because, but, so: a later letter

Check. 1. 79 CE is the conventional event-year, in Titus’s reign, not a year the set sentence states. 2. A sound sentence that keeps the later-letter limit and does not invent a reserved scene.

  1. Pompeii, and a death toll — neither is in the set date wording (or in the set pine extract, which history will use again this week).
  2. A translation can still be used, with its limits named. The habit is caution, not throwing the source away.
  3. “On the 24th of August, about the seventh hour…” (Firth, 1900, Attalus text).

Physics · g on the Earth, the Moon, and Mars

  1. No sourced orbital speed has been set as a figure for that job, so we will not invent one.

Logic · Valid forms: ponens, tollens, and disjunctive syllogism

Check. 1. If P then Q; P; therefore Q. If it is a square, then it is a rectangle; it is a square; therefore it is a rectangle. 2. Modus tollens: If P then Q; not Q; therefore not P. Denying the antecedent uses not-P to infer not-Q, and is invalid. The same non-square rectangle blocks that invalid form.

  1. That is affirming the consequent, already taught as invalid. A non-square rectangle is a rectangle and not a square.
  2. A sound invented pair, with not-P therefore Q (or not-Q therefore P).
