Latin · A negative result with ut nōn, a first look

Check. 1. Puella tam lentē venit ut eum nōn sequātur: she comes so slowly that she does not follow him (negative result). Puella manet nē eum sequātur: she stays in order that she not follow him (negative purpose). 2. Nē marks a negative purpose, not a result. A negative result uses ut nōn. 3. Tam signals the result: so slowly that the following does not happen. 4. Model: a negative result with ut nōn, a first look. Own words should match this idea: A negative result, in this first look, is marked by ut nōn and the already-taught present subjunctive, not by nē. Puella tam lentē venit ut eum nōn sequātur may be glossed she comes so slowly that she does not follow him. Nē still marks a negative purpose, as in last week’s Puella manet nē eum sequātur, she stays in order that she not follow him. Near-miss: Not nē eum sequātur, last week’s negative purpose. Not a positive result with ut and no nōn. Not sequētur, the future. Not ut nōn used as if it were a purpose clause. The fresh case should use the term correctly and not be copied from the card.

Exercises. 1. Model: Puella tam lentē venit ut eum nōn sequātur, and Puella manet nē eum sequātur, with the translations above. 2. Puer tam lentē venit ut eum nōn sequātur: he comes so slowly that he does not follow him.

Mathematics · A function not continuous at a point where it is not defined

Check. 1. f is not defined at 2, and continuity at 2 requires a defined value equal to the limit. 2. p(2) = 4, and lim x→2 (x + 2) = 4, so both conditions hold. 3. No. For x ≠ 1, h(x) = x + 1, so the limit is 2, but h(1) is not defined. 4. Model: a function not continuous at a point where it is not defined. Own words should match this idea: If a function is not defined at a, it is not continuous at a, even when the limit as x approaches a exists. Week 32’s invented function f(x) = (x² − 4)/(x − 2) is not defined at 2, and so is not continuous at 2, even though lim x→2 (x² − 4)/(x − 2) = 4 was already found by factorization. A formal epsilon argument remains reserved. Near-miss: Not a claim that the limit fails to exist at 2. The limit is 4. Not a claim that a missing value may be ignored when we ask about continuity. Not a formal epsilon argument, which remains reserved. The fresh case should use the term correctly and not be copied from the card.

Exercises. 1. Yes. f(0) = 0, and lim x→0 2x = 0. 2. No. For x ≠ 4, k(x) = x + 4, so the limit is 8, but k(4) is not defined.

Science · Official Example 20.9, peak voltage and peak power for AC

Check. 1. V₀ = 1.414 × 120 V = 170 V, official. P₀ = 2 × 60.0 W = 120 W, official. 2. V_rms. The official peak, V₀, is 170 V. 3. It would give the wrong relation V_rms = V₀/2, instead of V₀ = √2 V_rms. 4. Model: official Example 20.9, peak voltage and peak power for AC. Own words should match this idea: OpenStax official Example 20.9 asks for the peak voltage for 120-V AC power, and for the peak power consumption rate of a 60.0-W AC light bulb. Official household V_rms is 120 V, already taught last week. The book’s relation is V_rms = V₀/√2, so V₀ = √2 V_rms. The official arithmetic is V₀ = 1.414 × 120 V = 170 V. The official peak power is P₀ = 2 × 60.0 W = 120 W. Those figures are official book figures. The HTML of the book may drop the radical and look like V_rms = V₀/2; that dropped radical is not to be taught. The relation is V₀ = √2 V_rms, and the official factor is 1.414. Near-miss: Not last week’s official household wording as if the peak 170 V had already been computed then. Not the HTML’s dropped radical, V_rms = V₀/2, which is not the official relation. Not official Example 20.8 on cost, which remains reserved. Not a named utility rate. The fresh case should use the term correctly and not be copied from the card.

Exercises. 1. From 170 V to −170 V, official. 2. That official cost example is a later sitting, and is not to be replaced with a named utility rate.
