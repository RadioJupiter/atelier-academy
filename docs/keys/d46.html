Latin · Review of Capitula I–X: adjective agreement

Check. 1. Hortus magnus est. 2. Wrong agreement: puella is feminine, so magna, not *magnus. A correct sentence is Puella magna in hortō est. 3. Model: adjective agreement. Own words should match this idea: An adjective takes the gender, number, and case of the noun it describes. The endings may look like the noun’s, but the job is agreement, not a new family of nouns. Near-miss: Not a new chapter, and not Capitulum XI. Agreement is a rule you already use; today names it and practices it with I–X words only. The fresh case should use the term correctly and not be copied from the card.

  2. Puer magnus est.

Mathematics · Algebra XV: iterating a function

Check. 1. h(h(x)) = 3(3x) = 9x; h(h(2)) = 18, or 3 · 6 = 18. 2. f(f(x)) = 4x + 3. f(x) · f(x) = (2x + 1)² = 4x² + 4x + 1, a different expression. 3. Model: iteration of a function. Own words should match this idea: Applying the same function more than once: f(f(x)) is f applied to the result of f(x). It is composition of a function with itself, not multiplication of f by itself. Near-miss: Not f times f, and not the inverse f⁻¹ unless the lesson asks for an inverse. f(f(x)) is also written (f ∘ f)(x). The fresh case should use the term correctly and not be copied from the card.

  1. (f ∘ f⁻¹)(x) = x, the identity. That uses the inverse, already taught; iteration of f is f(f(x)), which for this f is 4x + 3, not x.
  2. k(k(x)) = (x + 5) + 5 = x + 10; k(k(1)) = 11.

Physics · g from G M / R², with sourced Earth figures

Check. 1. NASA Earth Fact Sheet. The same sheet lists a polar radius and a mean radius different from the equatorial radius, so Earth is not a perfect sphere. 2. This course uses G = 6.67 × 10⁻¹¹ as a labeled standard constant, not a number we tune to force a match, and not a classroom measurement. 3. Model: g from G M / R². Own words should match this idea: Near a sphere, the gravitational field g is G M / R², because F = G M m / R² and F = m g, so the m cancels. g is not the same symbol as G. Near-miss: Not a new measurement of G, and not a claim that 9.8 N/kg is exact at every place on Earth. The fact sheet itself lists more than one surface figure. The fresh case should use the term correctly and not be copied from the card.

The computed value is about 9.79 m/s² because G has three significant figures. 9.8 N/kg is a rounded working near-Earth value, consistent with the fact sheet's listed figures at that rounding, not an exact value at every place.

Logic · Modus ponens and modus tollens

Check. 1. If it is a square, then it is a rectangle. It is a square. Therefore it is a rectangle. 2. That form denies the antecedent (not P, therefore not Q). Modus tollens denies the “then” side (not Q, therefore not P). A non-square rectangle is a rectangle, so the invalid conclusion is false. 3. Model: modus ponens. Own words should match this idea: A valid form: If P, then Q; P; therefore Q. From a conditional and its “if” side, you may infer the “then” side. It is not affirming the consequent (If P then Q; Q; therefore P), which was taught as invalid last week. Near-miss: Not affirming the consequent, which uses the “then” side as a reason for the “if” side, and is invalid. A non-square rectangle is the already-taught counterexample to that invalid form, not to modus ponens. modus tollens. Own words should match this idea: A valid form: If P, then Q; not Q; therefore not P. From a conditional and the denial of its “then” side, you may infer the denial of its “if” side. It is not denying the antecedent (If P then Q; not P; therefore not Q), which was taught as invalid last week. Near-miss: Not denying the antecedent, which uses “not P” as a reason for “not Q,” and is invalid. A non-square rectangle is a rectangle and not a square, so “not a square” does not give “not a rectangle.” The fresh case should use the term correctly and not be copied from the card.

  1. A complete Together answer should match this idea: Modus tollens, and valid. Affirming the consequent: If it is a square, then it is a rectangle; it is a rectangle; therefore it is a square. A non-square rectangle is a counterexample.
  2. The fresh case should use the term correctly and not be copied from the card; the near-miss should be the one the lesson named, or a close equivalent.
