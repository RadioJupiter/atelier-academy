## Mathematics · Geometry XC: SSA when the given angle is obtuse, then a mixed practice {#math}
<p class="meta">40 min · Method: invented obtuse A = 120°, b = 2; no triangle if a ≤ b; one triangle if a > b; then a mix of the week’s acute cases</p>
<div class="learn" data-listen="en-US">

<div class="keyterms recall-terms" markdown="0">
<h4>Key terms (from earlier lessons)</h4>
<ul>
<li><a href="d146.html#term-the-ambiguous-case-ssa">the ambiguous case (SSA)</a> — Day 146</li>
</ul>
<p>Open a card if you need a reminder; then close it and use the term in your own words.</p>
</div>
<p>If the given angle A is obtuse, the height comparison of the acute case is not reused unchanged. In an obtuse triangle the side opposite the obtuse angle is the longest side, so if a ≤ b there is no triangle. If a &gt; b, there is one triangle. On invented figures, A = 120° and b = 2. If a = 2, or if a = 1, then a ≤ b and there is no triangle. If a = 2√3, then a &gt; b. The law of sines gives sin B = 2 × sin 120° / (2√3). Sin 120° = sin(180° − 60°) = sin 60° = √3/2, so sin B = 2 × (√3/2) / (2√3) = 1/2, and B = 30°, the acute value, because A is already obtuse and two obtuse angles cannot stand in one triangle. Then C = 180° − 120° − 30° = 30°, and the triangle is 120°-30°-30°. The figures are invented. Do not invent official measured sides.</p><p>A short mix of the acute cases already taught, still with A = 30° and b = 2: a = 1/2, none; a = 1, one right triangle; a = √2, two triangles; a = 2, one isosceles triangle.</p>

</div>

<div class="remember" data-listen="en-US">

<p class="kicker">Remember</p>

If A is obtuse and a ≤ b, there is no triangle. If a > b, there is one. On invented figures with A = 120° and b = 2, a = 2√3 gives one triangle, 120°-30°-30°.

</div>
