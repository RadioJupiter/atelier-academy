<div><dt>Definition</dt><dd>If a function is not defined at a, it is not continuous at a, even when the limit as x approaches a exists. <div><dt>Example</dt><dd>f(x) = (x² − 4)/(x − 2) is not defined at 2, because the denominator is 0 there. The limit as x approaches 2 is 4, already taught. Continuity at 2 would also require f(2) to be defined and equal to 4. Since f(2) is not defined, f is not continuous at 2.</dd></div>
<div><dt>Not this</dt><dd>Not a claim that the limit fails to exist at 2. The limit is 4. Not a claim that a missing value may be ignored when we ask about continuity. Not a formal epsilon argument, which remains reserved.</dd></div>
<div class="wide"><dt>Connects to</dt><dd>Yesterday’s definition of continuity at a point, and week 32’s limit where the function is not defined at the point. Filling the hole by defining a new function at 2 remains reserved.</dd></div>
</dl></article>
</div>
<p>Yesterday’s first look said that f is continuous at a only when f is defined at a and lim x→a f(x) = f(a). Both conditions are required. Week 32 taught an invented function that is not defined at the point in question: f(x) = (x² − 4)/(x − 2). At x = 2 the denominator is 0, so f(2) is not defined. The limit, found by factorization, is 4: (x − 2)(x + 2)/(x − 2) = x + 2 for x ≠ 2, and that approaches 4. The limit exists, but f is still not continuous at 2, because f is not defined there. The same holds for invented g(x) = (x² − 9)/(x − 3) at 3: the limit is 6, already practiced in week 32, but g(3) is not defined, so g is not continuous at 3. Filling a hole by defining a new function at the missing point remains reserved. A formal epsilon argument remains reserved. The functions are invented classroom examples.</p>
